Guia de Uso

Fluxo completo

1. Abra este arquivo no navegador (duplo clique)
2. Faça suas edições nos campos dos YCHs
3. Clique Salvar YCH.html (canto superior direito)
4. O arquivo YCH.html completo é baixado
5. Substitua o original na sua pasta pelo novo
6. Manda a pasta pro seu amigo hospedar ✓

Aspect Ratio — Qual usar?

16:9 → ych-16x9Widescreen. Ex: Easter Egg, Shooter YCH.
4:3 → ych-4x3Padrão. A maioria dos YCHs usa este. Ex: What YCH, Perspective, Blehh.
ych-carouselCarrossel padrão para a maioria dos casos.
ych-carousel2Para 16:9 mais largo. Ex: Shooter YCH.

Status — O que cada um faz

OpenBotão azul "Order This YCH" aparece.
ClosedBotão cinza desabilitado "Currently Closed".
LimitedBotão azul com alerta amarelo de poucos slots.
WaitlistBotão "Join Waitlist" com aviso roxo.
